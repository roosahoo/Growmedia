# Growmedia Website // HTML + CSS, JavaScript

A modern, responsive landing page concept built with HTML, CSS and vanilla JavaScript. 

The project focuses on creating a polished, modern web experience with strong visual hierarchy, responsive layouts, animations and bilingual content.

## Overview

This project is a landing page built around an AI marketing education concept. The design combines a dark green and pink visual identity with large typography, rounded UI elements, subtle grid patterns and animated transitions.

The page is structured into several sections. No frameworks or build tools are required.

<img width="949" height="470" alt="image" src="https://github.com/user-attachments/assets/ba62cb78-596b-4055-a2aa-2082dd55fee1" />

## Design

The design uses a strong visual contrast between deep green backgrounds and pink accent elements.

The page includes both Finnish and English content. The selected language is applied directly to the page without requiring a reload.

Language switching is handled with vanilla JavaScript by storing the translations in a language object and dynamically updating the corresponding DOM elements.

## Responsivity

The layout is designed to adapt to different screen sizes.

On smaller screens:

The navigation links are hidden,
the hero section changes to a single-column layout,
course cards stack vertically,
content grids become single-column layouts,
typography and spacing are adjusted,
 and footer content becomes vertically aligned
